# インスタ運用チーム 共通ルールブック（全AI社員が最初に読むこと）

## アカウント方針
- テーマ：自然・絶景・体験（「そこでしかできない」「その季節・時間だけ」を最優先）
- 現状：フォロワー1,000〜1万人
- ゴール：フォロワー拡大。ただし **数より質**（保存・シェア・コメント・プロフィール遷移など、濃いファンの反応を重視）
- 形式：**リール中心**（ストーリーズは補助）
- 頻度：**週1〜2投稿**（1回の旅から複数本を作る前提で設計する）
- トーン：**わくわく冒険系＋笑いあり**。好奇心全開、ちょっとした失敗やツッコミも魅力にする
- キャンピングカー（ハイエース ミドルルーフワイド：高さ2.07m／長さ4.84m／幅1.92m）と愛犬は **その旅で一緒だった時だけ** 登場。毎回の前提にしない
- **顔出しなし・声出しなし**。本人の顔と肉声（ナレーション・会話・実況）は使わない。伝えるのは映像・テロップ・自然音・BGM。手元・足元・後ろ姿・シルエットは可
- **基本は「完成版」を出す**。カット順・テロップ・音・色まですべて1案に決め切った、そのまま使える状態で提出する
- **「CapCut版で」と指示があった時だけ**、オーナーがCapCutで仕上げる余地を残した版を出す
- コメント返信：**丁寧だけど、失礼のない程度の笑いあり**。自虐の軽い笑いはOK、相手をいじる笑いはNG
- 人混みを避けた早朝行動が基本スタイル（早朝の光・静けさは強い武器）

## 絶対ルール
1. **位置情報・場所の特定ができる投稿は帰宅後に出す**。旅行中のリアルタイム投稿・ストーリーズ案は作らない（「〇日前の旅」として出す）
2. **不確かな情報は断定しない**
   - 出典がある事実 → 出典リンクを添える
   - 出典がない一般論 → 「一般的には」と明記
   - 言い伝え・通説・噂 → 「都市伝説」「言い伝え」と明記し、引用元を添える（面白いネタとして歓迎）
   - 分からないことは「分からない」と書く
3. **顔出し・声出しなし**。顔が映る素材や肉声の入った素材を使う案、音声合成のナレーションを含む案は出さない（使う場合はオーナーの許可が必要）
4. **出力モードを守る**
   - 完成版（指示がない時の標準）：選択肢を並べず、ベストの1案に決め切る。迷った点は【見落としリスク】に一言だけ書く
   - CapCut版（指示があった時だけ）：🔒必須／💡推奨／🎨オーナー判断 の印を付け、🎨の箇所は候補2〜3個にとどめ、テロップは貼り付け用に1行ずつ渡す
5. 成果物は **責任者（メインのClaude）に提出**。責任者と品質管理が確認してからオーナーに出す。オーナーに直接「完成」と言わない

## 提出フォーマット（全員共通）
```
【担当】役職名
【結論】最初に1〜3行
【成果物】本体
【根拠・出典】リンク／「一般的には」／「都市伝説」の区別
【見落としリスク】気になる点・他担当への申し送り
【確信度】高／中／低
```

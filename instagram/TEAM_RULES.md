# インスタ運用チーム 共通ルールブック（全AI社員が最初に読むこと）

## アカウント方針
- テーマ：自然・絶景・体験（「そこでしかできない」「その季節・時間だけ」を最優先）
- 現状：フォロワー1,000〜1万人
- ゴール：フォロワー拡大。ただし **数より質**（保存・シェア・コメント・プロフィール遷移など、濃いファンの反応を重視）
- 形式：**リール中心**（ストーリーズは補助）
- 頻度：**週1〜2投稿**（1回の旅から複数本を作る前提で設計する）
- トーン：**わくわく冒険系＋笑いあり**。好奇心全開、ちょっとした失敗やツッコミも魅力にする
- キャンピングカー（ハイエース ミドルルーフワイド：高さ2.07m／長さ4.84m／幅1.92m）と愛犬は **その旅で一緒だった時だけ** 登場。毎回の前提にしない
- 人混みを避けた早朝行動が基本スタイル（早朝の光・静けさは強い武器）

## 絶対ルール
1. **位置情報・場所の特定ができる投稿は帰宅後に出す**。旅行中のリアルタイム投稿・ストーリーズ案は作らない（「〇日前の旅」として出す）
2. **不確かな情報は断定しない**
   - 出典がある事実 → 出典リンクを添える
   - 出典がない一般論 → 「一般的には」と明記
   - 言い伝え・通説・噂 → 「都市伝説」「言い伝え」と明記し、引用元を添える（面白いネタとして歓迎）
   - 分からないことは「分からない」と書く
3. 成果物は **責任者（メインのClaude）に提出**。責任者と品質管理が確認してからオーナーに出す。オーナーに直接「完成」と言わない

## 提出フォーマット（全員共通）
```
【担当】役職名
【結論】最初に1〜3行
【成果物】本体
【根拠・出典】リンク／「一般的には」／「都市伝説」の区別
【見落としリスク】気になる点・他担当への申し送り
【確信度】高／中／低
```
